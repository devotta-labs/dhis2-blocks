<RegistryInstallCommand item="working-list" />

## Basic usage

Choose the controls your users need and place them inside `WorkingList`. This example includes saved views, column choices, filters, and the results table. It assumes DHIS2 app runtime and TanStack Query are already configured in your app.

```tsx
import {
    WorkingList,
    WorkingListColumnSelector,
    WorkingListFilterControls,
    WorkingListTable,
    WorkingListToolbar,
    WorkingListViewSwitcher,
} from '@/components/working-list'

export const BasicWorkingList = () => (
    <WorkingList
        programId="IpHINAT79UW"
        orgUnitId="y77LiPqLMoq"
        defaultPagination={{ page: 1, pageSize: 15 }}
    >
        <WorkingListViewSwitcher />
        <WorkingListToolbar>
            <WorkingListColumnSelector />
            <WorkingListFilterControls />
        </WorkingListToolbar>
        <WorkingListTable />
    </WorkingList>
)
```
