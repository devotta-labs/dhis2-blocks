The sidebar holds an app's pages, grouped under labels, with the current page
filled. On a desktop it folds to a rail of icons; on a window narrower than
768 pixels it becomes a sheet that slides over the page. It is the shadcn
Sidebar on the DHIS2 theme roles.

## Installation

<InstallCommand item="sidebar-menu" />

`sidebar-menu` holds the menu parts and installs `sidebar`, the frame, with
it. Install `collapsible` as well for groups of pages that open and close.

## Usage

```tsx
import { NavLink, Outlet } from 'react-router-dom'
import {
    Sidebar,
    SidebarContent,
    SidebarGroup,
    SidebarGroupLabel,
    SidebarInset,
    SidebarProvider,
    SidebarTrigger,
} from '@/components/dhis2/ui/sidebar'
import {
    SidebarMenu,
    SidebarMenuButton,
    SidebarMenuItem,
} from '@/components/dhis2/ui/sidebar-menu'
import { IconCalendar16, IconSearch16 } from '@dhis2/ui-icons'

export const AppLayout = () => (
    <SidebarProvider className="h-full">
        <Sidebar collapsible="icon">
            <SidebarContent>
                <SidebarGroup>
                    <SidebarGroupLabel>Patients</SidebarGroupLabel>
                    <SidebarMenu>
                        <SidebarMenuItem>
                            <SidebarMenuButton
                                render={<NavLink to="/today" />}
                                tooltip="Today"
                            >
                                <IconCalendar16 />
                                <span>Today</span>
                            </SidebarMenuButton>
                        </SidebarMenuItem>
                        <SidebarMenuItem>
                            <SidebarMenuButton
                                render={<NavLink to="/find" />}
                                tooltip="Find patient"
                            >
                                <IconSearch16 />
                                <span>Find patient</span>
                            </SidebarMenuButton>
                        </SidebarMenuItem>
                    </SidebarMenu>
                </SidebarGroup>
            </SidebarContent>
        </Sidebar>
        <SidebarInset>
            <header>
                <SidebarTrigger />
            </header>
            <Outlet />
        </SidebarInset>
    </SidebarProvider>
)
```

`SidebarProvider` fills its parent rather than the window, so the sidebar sits
below the DHIS2 header bar. Give the parent a height; the page scrolls inside
`SidebarInset`.

A router's `NavLink` sets `aria-current="page"` on the current link, which the
sidebar fills. Without a router, set `isActive` on the button. In Windows
forced colours the fill disappears, so the current page is outlined instead.

## Folding

Users fold the sidebar with `SidebarTrigger`, by clicking its edge
(`SidebarRail`), or with Ctrl or ⌘ and B. Set `collapsible` on `Sidebar`:

- `icon` folds it to a rail of icons. Give each `SidebarMenuButton` an icon
  and a `tooltip`, which names it while folded.
- `offcanvas`, the default, slides it out of view.
- `none` keeps it open.

It starts open; set `defaultOpen={false}` on `SidebarProvider` to start
folded, or `open` and `onOpenChange` to hold the state in your app. Read it
anywhere inside the provider with `useSidebar()`.

On a narrow window the trigger opens the sheet instead. The sheet closes when
a link in it is followed, unless the link opens a new tab or window, or a
download; buttons, such as a group's trigger, leave it open. It slides in from
the side the text starts on, even when only part of the page is right to left.

## Groups of pages

Wrap a menu item in a `Collapsible` to open and close its sub-pages:

```tsx
<Collapsible defaultOpen render={<SidebarMenuItem />}>
    <CollapsibleTrigger render={<SidebarMenuButton tooltip="Reports" />}>
        <IconVisualizationColumn16 />
        <span>Reports</span>
    </CollapsibleTrigger>
    <CollapsibleContent>
        <SidebarMenuSub>
            <SidebarMenuSubItem>
                <SidebarMenuSubButton render={<NavLink to="/reports/stock" />}>
                    <span>Stock</span>
                </SidebarMenuSubButton>
            </SidebarMenuSubItem>
        </SidebarMenuSub>
    </CollapsibleContent>
</Collapsible>
```

Sub-pages hide while the sidebar is folded to icons.

## Right to left

`side` follows the text direction: `left`, the default, is where a line
starts. Under `dir="rtl"` the sidebar docks on the right, and the trigger's
arrow and the rail turn with it.

## API reference

From `sidebar`:

- `SidebarProvider` — `defaultOpen`, `open` and `onOpenChange`.
- `Sidebar` — `side?: 'left' | 'right'`; `variant?: 'sidebar' | 'floating' |
'inset'`; `collapsible?: 'offcanvas' | 'icon' | 'none'`; `mobileTitle`, the
  sheet's accessible name ("Navigation").
- `SidebarHeader`, `SidebarContent` (scrolls), `SidebarFooter`,
  `SidebarSeparator`, `SidebarInput`.
- `SidebarGroup`, `SidebarGroupLabel`, `SidebarGroupAction`,
  `SidebarGroupContent`.
- `SidebarTrigger` and `SidebarRail` — `label` for their accessible name
  ("Toggle sidebar").
- `SidebarInset` — the page beside the sidebar.
- `useSidebar()` — `state`, `open`, `setOpen`, `openMobile`,
  `setOpenMobile`, `isMobile` and `toggleSidebar`.

From `sidebar-menu`:

- `SidebarMenu`, `SidebarMenuItem`.
- `SidebarMenuButton` — `isActive`; `tooltip`, shown while folded to icons;
  `variant?: 'default' | 'outline'`; `size?: 'default' | 'sm' | 'lg'`. Pass a
  link through `render`.
- `SidebarMenuAction` (`showOnHover`), `SidebarMenuBadge`,
  `SidebarMenuSkeleton` (`showIcon`).
- `SidebarMenuSub`, `SidebarMenuSubItem`, `SidebarMenuSubButton` (`isActive`,
  `size?: 'sm' | 'md'`).
