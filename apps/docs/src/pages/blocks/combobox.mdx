A combobox is a select with a search box. Use it when the list is too long to
scroll, such as facilities, villages, or option sets. It replaces the
filterable `@dhis2/ui` SingleSelect and MultiSelect.

## Installation

<InstallCommand item="combobox" />

## Usage

Pass the options as `items`. The list filters as users type, and
`ComboboxEmpty` shows when nothing matches:

```tsx
import {
    Combobox,
    ComboboxContent,
    ComboboxEmpty,
    ComboboxInput,
    ComboboxItem,
    ComboboxList,
    ComboboxTrigger,
    ComboboxValue,
} from '@/components/dhis2/ui/combobox'
import { selectTriggerVariants } from '@/components/dhis2/ui/select'

export const FacilityPicker = () => (
    <Combobox items={facilities} value={facility} onValueChange={setFacility}>
        <ComboboxTrigger className={selectTriggerVariants()}>
            <ComboboxValue placeholder="Choose a facility" />
        </ComboboxTrigger>
        <ComboboxContent>
            <ComboboxInput showTrigger={false} placeholder="Search" />
            <ComboboxEmpty>No facility matches</ComboboxEmpty>
            <ComboboxList>
                {(item: string) => (
                    <ComboboxItem key={item} value={item}>
                        {item}
                    </ComboboxItem>
                )}
            </ComboboxList>
        </ComboboxContent>
    </Combobox>
)
```

## Choose several

Add `multiple`, and show a checkbox beside each option with
`indicator="checkbox"`. The value is then a list. To show each choice as a
chip, make `ComboboxChips` the box and anchor the list to it:

<ExampleCard slug="combobox/multiple" />

```tsx
const anchor = useComboboxAnchor()

<Combobox items={programs} multiple value={chosen} onValueChange={setChosen}>
    <ComboboxChips ref={anchor}>
        {chosen.map((program) => (
            <ComboboxChip key={program} removeLabel={`Remove ${program}`}>
                {program}
            </ComboboxChip>
        ))}
        <ComboboxChipsInput id="programs" />
    </ComboboxChips>
    <ComboboxContent anchor={anchor}>
        {/* … */}
        <ComboboxItem value={item} indicator="checkbox">
            {item}
        </ComboboxItem>
    </ComboboxContent>
</Combobox>
```

## Options with labels

When options are objects, pass `itemToStringLabel` so the search and the
closed combobox use the option's name:

```tsx
<Combobox
    items={orgUnits}
    itemToStringLabel={(unit) => unit.displayName}
>
```

## API reference

- `Combobox` — `items`, `value`, `defaultValue`, `onValueChange`,
  `multiple`, and `itemToStringLabel`. `onInputValueChange` tells you what
  users type, for searching on the server.
- `ComboboxTrigger` — the closed combobox. Style it with
  `selectTriggerVariants()` to match the [Select](/blocks/select).
- `ComboboxValue` — the chosen option, or the `placeholder`.
- `ComboboxContent` — the list and its search box.
- `ComboboxInput` — the search box. Pass `showTrigger={false}` inside the
  list.
- `ComboboxList` — renders each option through its children.
- `ComboboxItem` — one option. `indicator?: 'check' | 'checkbox'`.
- `ComboboxEmpty` — shown when nothing matches.
- `ComboboxChips` — the box holding the chips and their input, framed like
  an input. `size?: 'default' | 'sm'`.
- `ComboboxChip` — one choice. `removeLabel` names its remove button.
- `ComboboxChipsInput` — the search box among the chips.
- `useComboboxAnchor` — a ref for `ComboboxChips`, passed to
  `ComboboxContent` as `anchor`.
