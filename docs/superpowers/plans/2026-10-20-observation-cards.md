# Observation Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small read-only shadcn registry block of cards that show one tracked entity's data values over time
(trend and last recorded), fed by one hook.

**Architecture:** One workspace package, `packages/blocks/observation-cards`, ships two registry items in the
style of program-rules: a `registry:hook` (`use-tracked-entity-observations`), which fetches events and metadata
and turns them into neutral series through pure internal files, and a `registry:block` (`observation-cards`),
whose cards take one hook result each as a prop and never fetch. New shared primitives (`badge`, `skeleton`,
`chart`) go in `packages/blocks/ui`.

**Tech Stack:** React 18, TypeScript, Tailwind v4, shadcn on Base UI, Recharts (through shadcn `chart`),
`@tanstack/react-query`, `@dhis2/app-runtime`, `zod`, `better-result`, `@dhis2/d2-i18n`,
`@dhis2/multi-calendar-dates`, vitest (node and browser), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-10-20-observation-cards-design.md`

## Review Focus

1. **Date strings in mixed forms** (`2026-03-12T00:00:00.000`, zoned `2026-03-12T00:00:00.000Z`, date-only) must
   order correctly and display the right day. Test in Task 2.
2. **Numeric values that don't parse** (`""`, `"abc"`, `"71.40"`, `"6"`): decimals parse; garbage is left out of
   the trend and never crashes or plots as 0. Test in Task 2.
3. **More events than one page**: a person with more than `pageSize` events gets every event. Test in Task 3.
4. **Legend boundaries and gaps**: a value equal to a legend's `endValue` falls in the next legend; a value in a
   gap or outside every legend has no colour and no badge. Test in Task 5.
5. **Option code missing from the option set** (option deleted or renamed): show the raw code with no colour, not
   a blank. Test in Task 5.

    color?: string
}

export interface TrackerEventRecord {

    programStage: string
    status: string
    occurredAt?: string
    createdAt?: string
