A spinner tells users that the app is working on something, such as
loading records or saving a form. It looks like the `@dhis2/ui`
CircularLoader.

## Installation

<InstallCommand item="spinner" />

## Usage

```tsx
import { Spinner } from '@/components/dhis2/ui/spinner'

export const LoadingRecords = () => <Spinner label="Loading records" />
```

Give it a translated `label` that says what is loading: screen readers
announce it as a status. Without a `label`, the spinner is hidden from screen
readers, for when text beside it already says what is happening.

## Sizes

The sizes follow the CircularLoader:

- Default, `size-4`, for inside a button or next to a line of text.
- Small, `className="size-6 border-4"`, for a card or a panel.
- Medium, `className="size-12 border-6"`, for the middle of a page.

## When to show one

- Show it where the content will appear, so users know what they are
  waiting for.
- In a button, put it before the label and change the label to say what is
  happening, such as "Saving…". Leave out the spinner's `label`, since the
  button's label already says it.
- Keep what is already on screen while new data loads, and show a small
  spinner beside it, instead of blanking the page.

## API reference

`Spinner` takes every prop of the HTML `span` element. Use `className` for
the size and `label` for what it announces.
