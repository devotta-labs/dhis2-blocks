This preview reads the organisation units of the user signed in to the preview
host. That user can reach a whole country, so the selector shows search. A user
with a few clinics gets a menu, and a user with one gets a plain label.

## In your navigation

Wrap the app in `ClinicProvider`, and put `ClinicSelector` at the top of the
app's navigation, where it stays while the links below collapse. The block
brings no navigation of its own, so pass `collapsed` yourself when yours is
narrowed to icons. Collapsed, the selector shrinks to the clinic's initial,
with the name in a tooltip.

```tsx
import { ClinicProvider, ClinicSelector } from '@/components/clinic-selector'

export function AppShell({ children }: { children: React.ReactNode }) {
    const [collapsed, setCollapsed] = useState(false)
    return (
        <ClinicProvider>
            <aside>
                <ClinicSelector collapsed={collapsed} />
                <nav aria-label="Application navigation">
                    {/* links, hidden or narrowed while collapsed */}
                </nav>
            </aside>
            {children}
        </ClinicProvider>
    )
}
```

The selector needs an app-runtime `DataProvider` and a React Query
`QueryClientProvider` above it.

## Reading the clinic

Call `useClinic()` anywhere under the provider to scope a page to the current
clinic.

```tsx
import { useClinic } from '@/components/clinic-selector'

function Visits() {
    const { clinic, status } = useClinic()
    if (status !== 'ready' || !clinic) {
        return null
    }
    return <VisitList organisationUnit={clinic.id} />
}
```

`clinic` is `{ id, displayName, path }`. `status` is `pending` while the
clinics load, `ready` once they are loaded and checked, `failed` if they could
not be loaded and `none` if the user has no organisation units. `clinic` is only
set when `status` is `ready`, and can still be unset then, when the host passed
a `value` the user cannot work at. `useClinic()` also returns `setClinic` and
`retry`.

## More than a few clinics

A user with a district, or with more than eight clinics, gets a search box.
Below a district, the menu also lists **All clinics** in the user's own
hierarchy by name, twenty at a time, with **Show more** at the end of the list,
so a user with thousands of clinics can browse without typing. Search runs on
the server over the same hierarchy and pages the same way.
The clinics the user picks by search are kept as **Recent**, newest first, five
at most, above their assigned units. A user can never pick a unit outside
their hierarchy, and a remembered unit they lose access to drops out.

## One or a few clinics

A user with one clinic sees a label and no button. A user with up to eight
clinics and no districts sees a menu without search. This example runs on a
made-up user, because the preview host's user can reach every clinic. The
`stubClient` in the Code tab shows how to give the block your own data layer
with `createClinicClient`.

## Controlling it

With no `value`, the provider chooses the clinic and remembers it, and pages
read `useClinic().clinic`. To keep the choice somewhere you own, such as the
URL, pass `value`, a clinic id, and `onValueChange`, which receives the picked
clinic. The host then decides: a pick changes nothing until the host passes it
back as `value`. Whenever `value` changes to another of the user's clinics,
after a pick or the back button, the provider remembers it and announces it.

```tsx
import { useNavigate, useParams } from 'react-router-dom'

function App() {
    const { clinicId } = useParams()
    const navigate = useNavigate()
    return (
        <ClinicProvider
            value={clinicId}
            onValueChange={(clinic) => navigate(`/clinics/${clinic.id}`)}
        >
            <ClinicSelector />
            <Visits />
        </ClinicProvider>
    )
}
```

Pages still read `useClinic().clinic`: it is the clinic for `value` once it has
been checked. A `value` the user cannot work at leaves `clinic` unset, and the
selector shows Choose a clinic. A host that calls clinics facilities or sites
can set `label` and `searchPlaceholder` on `ClinicSelector`. Pass `open` and
`onOpenChange` to own whether the menu is open.

## What it remembers

The provider keeps the current clinic and the recent ones in the browser's
local storage, for each user. It is not shared across devices, and another user
signing in on the same browser starts clean. A host that wants the choice to
follow the user across devices controls it with `value`.
